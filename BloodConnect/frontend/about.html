OUR MISSION

Finding a blood donor should not feel complicated.

BloodConnect brings donor information, blood requests, matching and donation records together in one place. The goal is to reduce unnecessary steps between someone willing to donate and someone looking for blood.

✓
Discover compatible donors Search using blood group and location.
✓
Manage blood requests Create, track and respond to requests through the platform.
✓
Keep donation information organized Donor availability and completed donations can be tracked.
WHY BLOODCONNECT

Designed around the real blood-request journey.

Instead of treating blood donation as disconnected forms, BloodConnect connects the major steps together.

⌕

Donor discovery

Search registered donors using blood group and location.

+

Blood requests

Receivers can create requests containing the required blood group, component, units and hospital.

✓

Matching

The platform identifies donors who match the request requirements.

●

Availability

Donors can maintain their availability status for potential requests.

↗

Request tracking

Requests can move through stages such as pending, accepted, rejected and completed.

▣

Donation history

Completed donations can be recorded and viewed as part of the donor's history.

TECHNOLOGY

Built as a real full-stack application.

BloodConnect combines a browser-based frontend with a Node.js backend and MongoDB database.

HTML & CSS Interface and responsive page structure
JavaScript Frontend interactions and API communication
Node.js + Express Backend server and REST API
MongoDB User, request and donation data storage
FUTURE DIRECTION

The platform can grow beyond the first version.

The current system provides the foundation for a broader blood donation network. Future versions can connect more people, organizations and services.

Mobile application Access the network from smartphones.
Hospital integration Connect requests with participating hospitals.
Blood-bank integration Improve access to institutional blood inventory.
GPS-based discovery Improve location-based donor discovery.
Push notifications Notify donors about relevant requests.
Smart recommendations Assist with more intelligent donor matching.
